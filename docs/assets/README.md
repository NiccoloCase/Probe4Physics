# Paper illustration

`mvp-probing-setup.png` is the illustration from Figure 5 of the accompanying
paper, extracted without changing its content. It shows the adaptation of MVP
to video-only physical-plausibility probing. Video frames are adapted from MVP
(Krojer et al., 2025); see the paper bibliography and `../third_party.md` for
upstream attribution. The editable source layout is not included.
